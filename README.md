# Backing Trainer Pro

A web-based CDL backing maneuver training application by Belew Training Solutions.

## Features

- **Straight Line Backing** - Practice keeping your trailer centered with small corrections
- **Offset Backing** - Follow FMCSA exam-style offset paths
- **Parallel Parking** - Practice conventional and sight-side CDL parallel parking
- **Alley Dock** - Simulate tight-space 90-degree alley dock backing
- **AI Voice Coach** - Vocal guidance for training maneuvers
- **Resources** - Links to YouTube training materials and sponsors

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Navigate through the dashboard to select a training maneuver

## Project Structure

- `index.html` - Main HTML file
- `style.css` - Styling and layout
- `router.js` - Client-side routing logic
- `voice.js` - Web Speech API voice functionality
- `app.js` - Screen definitions and navigation handlers

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Web Speech API
